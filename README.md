# Sluck

Играбельный браузерный прототип динамичного roguelike в мистическом Нью-Йорке 90-х. Ночной инспектор везёт Искру рассвета через город и преследует Сайласа Рука, который гасит маяки. Нужно не потерять его след и сохранить караван при смене уличного маршрута.

Сейчас доступна **уличная погоня** по трём районам. Канализация с камерой от третьего лица и прыжок в воздух относятся к следующему этапу.

## Как играть

1. Соберите колоду из четырёх героев и отправьте караван. В экипаже четыре активных места и два места запаса.
2. Нанимайте героев за души, полученные в боях. Перетащите героя на другого того же ранга, чтобы слить их в случайного героя из выбранной четвёрки более высокого ранга.
3. На двух развилках выберите левый или правый уличный путь и запечатайте соответствующую подворотню за заряд Нити рассвета. Прямой путь даёт души, но оставляет обе подворотни открытыми и сокращает время погони.
4. После каждого ключевого боя выберите на Колесе погони одну награду: случайного героя, усиление атак экипажа на 25% или защитную печать от следующего прорыва.
5. У маяка выдержите финальный бой до зажигания света. Если здоровье Искры или время следа достигнет нуля, попытка закончится.

Пять типов хранителей имеют разные роли: Гаргулья бьёт бронированных врагов, Химера поражает стаи, Ангел замедляет духов, Орёл догоняет бегунов, Атлант усиливает соседей. Все пять доступны для выбора колоды; постоянные модификации открываются по мере прохождения.

## Управление

| Действие | Телефон | Компьютер |
| --- | --- | --- |
| Нанять героя | Коснитесь одной из двух карт найма | Нажмите на карту |
| Слить героев | Перетащите между местами экипажа | Перетащите мышью |
| Применить Нить рассвета | Нажмите кнопку Нити | Нажмите кнопку Нити |
| Выбрать путь или награду | Коснитесь варианта на экране | Нажмите на вариант |
| Камера | Перетащите свободную улицу, сведите или разведите пальцы | Перетащите улицу, используйте колесо мыши |

## Запуск

Нужен Node.js. Из корня проекта:

```bash
node tools/dev-server.mjs
```

Откройте адрес, который покажет сервер. Для проверки и сборки:

```bash
node tools/check.mjs
node tools/build.mjs
```

Проверка типов использует TypeScript через `npx`; при первом запуске может потребоваться доступ к npm. Сборка создаёт `dist/sluck-<version>.zip`. На Windows доступны `run.bat`, `check.bat` и `build.bat`.
